# Kalsofte ERP — Automated Test Suite
### Powered by Playwright | Video Recording | HTML Report

---

## ✅ Prerequisites
- Node.js v16+ installed on your machine → https://nodejs.org
- Your Kalsofte app running at http://172.16.16.40:3000

---

## ⚙️ STEP 1 — Configure credentials
Open `tests/config.ts` and update:
```ts
username: 'YOUR_USERNAME',   // ← your actual username
password: 'YOUR_PASSWORD',   // ← your actual password
```
Also verify the selector values match your app's HTML if needed.

---

## 📦 STEP 2 — Install dependencies
Open terminal in this folder and run:
```bash
npm install
npm run install:browsers
```

---

## ▶️ STEP 3 — Run all tests (with browser window visible)
```bash
npm run test:headed
```

Or run specific suites:
```bash
npm run test:auth        # Only login/logout tests
npm run test:crud        # Only transaction CRUD tests
npm run test:validation  # Only validation tests
```

---

## 📊 STEP 4 — View the HTML report
```bash
npm run report
```
This opens a browser showing pass/fail for every test case.

## 🛠️ Troubleshooting

**Tests can't find elements?**
→ Open `tests/config.ts`, inspect your app's HTML (F12 in browser), and update the selectors to match.

**Video is blank/black?**
→ Change `headless: false` to `headless: true` in `playwright.config.ts` — some display configurations need headless mode for recording.

**Test times out?**
→ Increase `timeout: 60000` in `playwright.config.ts`
